# 一家言 (Cicada)

> 究天人之际，通古今之变，成一家之言。—— 司马迁《报任安书》

「一家言」是一款基于纯 Kotlin 与 Material Design 3 构建的《史记》数字人文研读与典籍精读 Android 应用程序。项目融合了现代移动交互设计与古典文献学排印美学，为研读太史公三千年通史提供多维度的数字探索工具。

## 核心功能

### 1. 沉浸式典籍精读
- **段落标引（Purple Numbers）**：正文全量配备微型标引锚点，支持精确到段落的摘句、书签收藏与本地古典引文卡片导出。
- **三家注疏行内对齐**：全书 14,595 条三家注（集解、索隐、正义及考证佚存）与正文实现 100% 拓扑段落绑定，阅读时就地展开研读。
- **白话译文对照**：支持逐段对照阅读，随心切换显示。
- **生僻字与多字重排版**：采用思源宋体（Noto Serif SC）可变字体，针对古籍正文提供 1.8 倍典雅行高与自适应字间距。

### 2. 史记“十表”网格解析
- 针对古籍最具挑战性的“十表”（三代世表、十二诸侯年表、六国年表等 13 张大表）自研动态空格公约跨度算法。
- 实现表头与数据行自动对齐、首列行标固定以及横向联动平滑滚动，并支持全屏铺开研读。

### 3. 先秦两汉历史知识图谱
- 基于 Canvas 深度定制的关系图谱与世系拓扑。
- 收录三代古帝世系、春秋五霸、战国四公子及楚汉争霸双雄阵营核心人物因果脉络，支持双向血脉追溯与手势缩放。

### 4. 统一编年长河
- 横跨上古三代、春秋战国、大秦一统至楚汉西汉的 2D 历史长河，以水墨曲水流线形式串联 19 大历史枢纽节点，支持一键定位原著篇章。

### 5. 成语典故与经典战役
- 收录出自《史记》的成语典故原文出处与词义释解。
- 梳理 20 余场决定先秦两汉历史走向的关键战事始末。

### 6. 金石雅致主题与典籍卡片
- 内置宣纸、磁青线装、天青竹简三种古典纸墨风格及玄青夜读模式。
- 内置离线汉字转换引擎（基于双向 Trie 树最长匹配），支持全文界面与典籍文本在简体中文与繁體中文之间无缝切换。
- 引文卡片采用二分逼近字号算法排版，可一键渲染并保存高分辨率书页图片至相册。

## 自研标注规范（OAM 简述）

采用中文古典单字代码作为文法标识，用数学尖括号 `⟪` 与 `⟫` 成对包裹，既不产生转义冲突，又保留古典金石气质：

```text
⟪代码 正文⟫            基本形式（如 ⟪人 黄帝⟫、⟪地 阪泉之野⟫）
⟪代码 显示词|索引键⟫   别名映射（如 ⟪人 政|嬴政⟫ 渲染为“政”，索引指向“嬴政”）
```

详见完整规范文档：[ANNOTATION_SPEC.md](docs/ANNOTATION_SPEC.md)。

## 现存已知局限与未来规划

1. **个别超生僻字回退机制**：应用虽已完整内置 24MB 思源宋体（Noto Serif SC，涵盖 BMP 基本区及 Ext-A 扩展区逾 3 万个汉字），但《史记》正文与三家注中仍有数十个罕见的先秦西汉专名古字属于超大字集 Unicode Ext-B/C 扩展区（如西汉侯国地名“𨙻” U+2867B、古人名“𡰥” U+21C25 等）。若打包全量 Ext-B~I 字体（动辄 100MB+）会极大膨胀移动端安装包，因此这部分极少数生僻字依赖 Android 系统的字体回退链（Fallback）渲染；在主流 ROM 上会平滑回退为系统黑体显示，在部分裁减了扩展字库的极简 ROM 上可能会显示为字形缺失方块。
2. **移动端十表超宽排版**：在大字号配置下，包含十余列的年表需横向滚动较长距离，后续版本将探索针对移动设备优化的竖排折叠与分栏交互模式。
3. **知识图谱节点覆盖**：当前知识图谱集中于古帝世系、战国策士与楚汉双雄，后续将依托已对齐的 2 万余条实体词条逐步拓展各诸侯国次级人物脉络。

## 本地构建与测试

### 环境要求
- JDK 17
- Android SDK 36 (Build Tools 36.0.0)
- Python 3.10+ (仅用于执行语料与 ETL 脚本)

### 常用命令

```bash
# 运行 Android 单元测试
./gradlew testDebugUnitTest

# 构建 Debug 安装包
./gradlew assembleDebug

# 校验语料与数据库完整性
python etl/verify_corpus.py
python etl/verify_db.py app/src/main/assets/opusone.db --committed
python etl/verify_tables.py

# 从源语料重新编译数据库
python etl/build_from_corpus.py app/src/main/assets/opusone.db
```

## 持续集成 (CI/CD)

- **Android CI (`android.yml`)**：在每次推送与 PR 时触发，执行 JDK 17 环境下的单元测试与 Debug APK 构建。
- **Python CI (`python.yml`)**：多版本矩阵（Python 3.10 / 3.11 / 3.12）校验语料语法、十表格网格守恒以及数据库双向往返编译一致性。
- **Release CI (`release.yml`)**：推送 `v*` 语义版本标签时自动触发，基于配置的 release 签名密钥完成 R8 混淆、签名与校验和生成，并自动发布 GitHub Release。
