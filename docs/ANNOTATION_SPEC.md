# OAM — OpusOne Annotation Markup（一家言古典标注规范）v1.1

> 本文定义「一家言」古籍标注语法的权威规范。
> 任何写入 `sections.tagged_content` 等语料字段的内嵌标注，必须符合本规范。

## 1. 设计原则

1. **古典金石气质**：采用中文古典单字代码作为首选文法（人、地、官、族等），彻底摆脱西方缩写与机器工程痕迹。
2. **单一包裹结构**：一种包裹符覆盖全部类型，类型由单字代码声明，不再按类别切换括号。
3. **纯文本安全**：包裹符选用典籍正文中绝不出现的数学双尖括号 `⟪` 与 `⟫`，无需转义。
4. **语义与样式分离**：代码只声明语义；颜色/下划线等视觉表现由客户端古典主题决定。
5. **双向兼容性**：解析引擎与校验工具对历史双字母代码（PE, PL, OF 等）保持全量向下兼容。

## 2. 语法

```
⟪代码 正文⟫            基本形式
⟪代码 显示词|索引键⟫   别名形式：正文渲染「显示词」，实体点击/检索使用「索引键」
```

- 包裹符：`⟪`（U+27EA）与 `⟫`（U+27EB），成对出现，不得嵌套。
- `代码`：中文单字（推荐）或两位大写 ASCII 字母（兼容），后跟**恰好一个**空格。
- `正文`：除 `⟪` `⟫` 外的任意字符；`|` 之后的子串为索引键，不参与渲染。
- 未定义代码按 `录` / `TX` 语义降级：正常渲染、可点击、无专属样式。

## 3. 类型代码对照表

| 古典代码 | 兼容代码 | 语义 | 默认高亮 | 说明 |
|:---:|:---:|---|:---:|---|
| **人** | `PE` | 人物 | 开 | 人名、字号、尊号、称谓 |
| **地** | `PL` | 地名 | 开 | 行政区、国都、山川、要塞、场所 |
| **官** | `OF` | 官职 | 开 | 职官、爵位、封号 |
| **族** | `CL` | 邦国氏族 | 开 | 诸侯国、氏族宗族、朝代系属 |
| **群** | `ID` | 身份群体 | 关 | 阶层、流派、群体称谓（如儒者、刺客） |
| **器** | `AR` | 器物名物 | 关 | 礼器、兵戈、宝物、传世重器 |
| **生** | `BI` | 生物名物 | 关 | 异兽、战马、祥瑞动植物 |
| **思** | `CO` | 思想天命 | 关 | 观念、天命、制度、哲学范畴 |
| **历** | `AS` | 天文历法 | 关 | 岁星、天象、节令、纪元甲子 |
| **数** | `QU` | 数量度量 | 关 | 数字、度量衡 |
| **语** | `CY` | 成语典故 | 开 | 后世成语、典故的原文出处 |
| **战** | `MV` | 军事动词 | 开 | 进攻、驻防、包围、征伐等战事行动 |
| **刑** | `XV` | 刑罚动词 | 关 | 诛杀、腰斩、流放、貶黜类动词 |

| **录** | `TX` | 泛指标注 | 关 | 兜底类型：可点击、无专属样式 |

## 4. 示例

```
⟪人 黄帝⟫者，⟪族 少典⟫之子也。⟪战 战⟫于⟪地 阪泉之野⟫。
⟪语 九鼎⟫未复，⟪人 政|嬴政⟫立。
```

渲染结果（高亮关闭时仍保留点击语义）：

> 黄帝者，少典之子也。战于阪泉之野。
> 九鼎未复，政立。

## 5. 客户端契约

- 渲染：`正则 ⟪([A-Za-z]{2}|[\u4e00-\u9fa5]) ([^⟪⟫]+?)⟫` 逐段解析；`|` 前为显示词，`|` 后为 `ENTITY_CLICK` 注解键。
- 过滤：关闭某类型仅移除视觉样式，**点击注解与链接必须保留**。
- 清洗：对外导出（复制/分享）时剥除全部标记，仅留纯净古籍原文字符。

## 6. 版本演进

- **v1.0**：双字母代码形式（PE, PL 等）。
- **v1.1（当前）**：全面升级为古典单字汉化代码（人、地、官、族等），同时对 v1.0 保持 100% 向下兼容。
